# Digital Electronics Master Handbook & Handwritten Notes

## Overview
This package contains the complete, comprehensive **Digital Electronics Master Handbook** covering all 5 academic units:
1. **Unit I:** Combinational Logic Design (Adders, Subtractors, Look-Ahead Carry, K-Maps, MUX/DEMUX, Code Converters)
2. **Unit II:** Sequential Logic Design (Latches, Flip-Flops, Master-Slave JK, Registers, Counters, Sequence Generators)
3. **Unit III:** State Machines (Mealy vs. Moore, State Minimization, Sequence Detectors, ASM Charts & Realization)
4. **Unit IV:** Digital Logic Families & PLDs (TTL, CMOS, Noise Margins, PROM, PAL, PLA, CPLD, FPGA)
5. **Unit V:** Introduction to VHDL (Entity, Architecture, Modeling Styles, Flip-Flop & MUX Synthesizable Templates)

Plus **50 Practice MCQs** (10 per unit) with full step-by-step solutions and **5 One-Page Quick Revision Cheat Sheets**.

## 🚀 How to Open and Use

### 1. View the Interactive Handwritten Notebook (HTML)
- Simply **double-click** `Digital_Electronics_Handwritten_Notebook.html`.
- It will open immediately in your default web browser (**Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari, or Opera**).
- Works out-of-the-box on Windows, Mac, Linux, Android, and iOS.

### 2. Export / Save as a Printable PDF Booklet
1. Open `Digital_Electronics_Handwritten_Notebook.html` in your browser.
2. Click the red button at the top: **"🖨️ Print / Save as PDF"** (or press **`Ctrl + P`** on Windows / **`Cmd + P`** on Mac).
3. Set the destination to **"Save as PDF"**.
4. Set margins to **"Default"** or **"None"** and check **"Background graphics"**.
5. Click **Save** to create an illustrated, printable study book.

### 3. Plain Markdown Version
- Open `Digital_Electronics_Handbook.md` in any Markdown viewer, VS Code, Obsidian, Notion, or GitHub.
